# 可选扩展验收清单

本清单逐项对应题目 PDF 的 29 条可选扩展，记录本轮补充后的实现证据与限制。`已实现` 指应用中存在可运行的实现；`部分实现` 指还有明确缺口。真实外部模型、生成媒体服务和实体麦克风的效果，需要独立验证，不能从 Mock 或模拟测试推断。

## 实时语音

| 题目项目 | 状态 | 实现证据与边界 |
| --- | --- | --- |
| 自动检测用户开口并完成自然打断 | 已实现，待设备验证 | [automatic.mjs](../src/voice/automatic.mjs) 使用本地 Silero V5 VAD；候选语音先压低角色音量，持续有效发言才取消当前轮。设置中可开启自然语音。 |
| 区分真正的打断与“嗯”“对”等附和 | 已实现，规则判断 | [utterance.mjs](../src/voice/utterance.mjs) 综合文本和持续时间；短附和恢复原播放，实质发言触发打断。长附和、口音和噪声仍可能误判。 |
| 回声消除，避免角色听到自己的声音 | 部分实现 | 请求浏览器 `echoCancellation`、`noiseSuppression`、`autoGainControl`，并过滤与当前播放台词匹配的回声。没有独立声学回声消除器，也未完成扬声器、蓝牙耳机或手机外放实测。 |
| 流式字幕 | 已实现，句级 | [providers.mjs](../server/providers.mjs) 用增量 JSON 解析器校验完整台词后立即发出；[stream.mjs](../src/stream.mjs) 读取 NDJSON；无需等整轮完成即可播放第一句。字幕随语音进度展开，非逐 token 的实时音素对齐。 |
| 展示语音首包延迟或关键阶段耗时 | 已实现 | [speech.mjs](../src/speech.mjs) 区分首个音频网络块与实际开始播放；会话详情的诊断页显示当前值及服务端首句/首包统计。本地预录音频与在线 TTS 的指标来源会不同。 |
| 断线重连和会话恢复 | 已实现，有限恢复 | [useExperience.jsx](../src/useExperience.jsx) 对可恢复断流做最多三次查询；[session-store.mjs](../server/session-store.mjs) 保存服务端状态与逐句确认进度；[journal.mjs](../src/journal.mjs) 保存浏览器会话。恢复从未说完的一句重播，非采样级无缝续播。 |

语音实现与时间戳约束详见 [AUDIO.md](AUDIO.md)。自动语音需要 HTTPS 或 localhost、麦克风权限，以及浏览器识别或配置的 STT 服务。

## 验证边界

- 自动化测试使用可控流和模拟识别事件证明取消、时序及判断逻辑；不能替代实体麦克风和真实中文识别效果验收。
- 本地视频已在 Playwright Chromium 的 1280×800 / 390×844 视口验证实际解码、时间推进、暂停、seek、退出、错误恢复和 alpha 分层。旁白版均检测到一条真实音轨、持续增长的解码字节与非零 WebAudio RMS；暂停时间差为 0，seek 到 4.5 秒恢复正确后句，关闭后没有迟到事件。H.264 不可解码的 Chromium 使用 WebM。
- 口型是实际振幅加估算元音，生成媒体的连续性是参考图与提示约束，回声处理依赖浏览器能力。上述三项均不应描述为精确对齐、保证身份一致或已完成声学效果验证。
- 图片/视频真实 Provider 的额度、延迟、内容效果、远端取消和多设备编解码仍需部署后联调。无密钥体验始终明确使用留影或本地回放。
