## 真实浏览器音频推理

`AUDIO_TEST_URL=http://localhost:4176 node scripts/audio-runtime.mjs` 在开发服务上实际运行同源 Silero V5 ONNX/WASM，输入预录的虚拟麦克风。检测序列为 candidate → interrupt → transcript，停止后所有轨道为 ended。此处 STT 回包为测试夹具，不能代表真实供应商识别能力。

同次实际 MP3 MediaSource 播放的分析峰值约 0.953，元音口型随音频变化；本地夹具首个网络块 8ms，实际播放 12ms。数字只是本地测试观测，不代表线上延迟。另一次真实音频图静音测试得到 RMS 0.0887 → 0 → 0.1250。脚本直接导入源码模块，需开发服务；不适用于仅提供 dist 的生产静态入口。
