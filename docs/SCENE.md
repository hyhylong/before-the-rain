# 角色动画与视频演出

## 角色配置

`public/character.json` 定义成年角色身份、配色、照片/视频资源、呼吸/眨眼/视线参数，以及每个动作的优先级、过渡时间和关节目标。`src/scene/animation.mjs` 使用 Zod 验证；配置缺失或不合法时使用同模块中的安全默认配置，角色仍可呈现。

动作由 `ActionScheduler` 统一仲裁。倾听优先级 100、思考 90、举照片 60、挥手 50、普通点头 30、待机 0。切换输入状态会递增动作 epoch，旧轮请求不能进入当前调度；关节按动作配置的 blendSeconds 过渡。情绪采用独立的权重混合器，不会因一个动作取消而突然重置面部。

## 造型与自然动作

`src/scene/character.mjs` 单独构建 Mira 的模型，保留 26 岁成年角色、琥珀色雨衣、银色星形发夹与相机。面部在同一连续曲面上塑造鼻梁、鼻尖、脸颊和眼窝，并以顶点颜色表现腮红；衣袖使用连续轮廓，头发由发帽与可轻微跟随动作的发束组成。场景使用暖色主光、正面补光与窗侧轮廓光。

眼白的杏仁形轮廓写入 stencil，虹膜与高光只在该轮廓内显示，随眼睛一起眨动；渲染器必须开启 `stencil: true`。嘴唇为有面积的上下唇曲面，使用同一个微笑 morph target 跟随情绪权重，开合与元音宽度仍由音频驱动。

`PresenceMotion` 使用固定种子的变化间隔生成注视目标、重心转移和眨眼，视线先移动，头部较慢跟随；左右眨眼错开 12ms，偶尔出现连续两次眨眼。身体与头部具有不同幅度的呼吸和轻微不对称姿态，音频振幅经过平滑后参与头肩、手臂与发束动作。点头包络约 1.05 秒，挥手包络约 2.6 秒；动作状态持续存在也不会无限重复摆动，切换动作重新计时。照片在举手开始 280ms 后显示，倾听或思考可立即抢占该动作。

挥手时前臂弯回脸侧，使手部留在手机视口中；结束后肩肘平滑回到待机姿态。照片随手掌移动，但单独补偿父级旋转并保留轻微倾角，画面朝向相机，抓握位置位于下边框。

`reducedMotion` 将呼吸、注视和重心等动态缩小为常规幅度的 10%，关闭自动眨眼、雨线移动与闪光；保留剧情动作、情绪和口型反馈。

`MiraScene` 继续接受原有 props，新增 `viseme: {aa, ee, oo, closed, source}`。口型由不同元音宽度/开合与实际音频振幅共同驱动。没有使用正弦波伪造语音能量；无音频能量时嘴部闭合。实际振幅也轻微驱动头部与肩部。来源为拼音估算的时间轴时属于估算口型，不能宣称是服务商返回的精确音素对齐。

渲染的 canvas 提供 `__capture()`：先渲染当前帧，再返回本地 PNG。用于生成式媒体的角色参考图与原创视频制作；不会截图界面控件或用户输入。配置里的图片路径只能是应用内本地路径。

## 原创视频

`public/video/` 包含以下真实视频资源，每段 8 秒：

- `memory.webm` / `memory.mp4`：原创 Three.js Mira 举起照片，然后画面过渡到原创灯塔插画并缓慢推进。
- `rain.webm` / `rain.mp4`：同一咖啡馆、同一 Mira，从雨夜逐渐过渡到雨停，并以挥手结尾。默认播放 WebM，兼容未编译 H.264 解码器的 Chromium；MP4 可用于支持 H.264 的浏览器和录屏导出。
- `rain-overlay.webm`：具有 alpha 通道的 VP9 雨线视频，在主视频上独立分层；雨停时随时间减淡。
- `memory.jpg` / `rain.jpg`：同一片段的封面，在视频尚未首帧解码时承接显示，避免黑屏。
- `manifest.json`：资源来源、时长和剧情字幕/特效时间点。

视频并非第三方电影、AI 生成视频或角色替身；由本项目自己的 3D 角色/场景及原创插画实际渲染录制。两个片段分别复用 `public/audio/33289d23ebef.mp3` 与 `114f3e794f68.mp3` 的中文旁白，延后 350ms 混入视频音轨；来源见 `ASSETS.md`。环境声音是 ffmpeg 合成的低音量粉红/棕色噪声，未使用外部音乐或私人录音。

重新生成（需要 Playwright Chromium 和 ffmpeg）：先运行 `npx vite --host 0.0.0.0 --port 4175`，另一个终端执行 `node scripts/generate-video.mjs`。生成器使用隔离的 `CaptureEntry.jsx`，不会依赖完整应用或真实服务。可以通过 `CLIP_SOURCE_URL` 指定另一个 Vite 地址。

## VideoStage

组件路径：`src/media/VideoStage.jsx`。输入：

```jsx
<VideoStage clip="memory" signal={turnSignal}
  onState={handleState} onCue={handleCue}
  onError={handleError} onClose={closeVideo} />
```

生成视频也可传 `src`、`poster`、`timeline` 覆盖本地资源。所有片段预加载，播放前显示封面，加载与失败有明确状态。具备播放/暂停、声音开关、可拖动进度与关闭。视频结束后淡出回到常驻 3D 场景；失败时保留封面，并提供重试和返回。

本地片段的配音内嵌视频，字幕为旁白原文，按录音中的实际句间停顿切换，和事件一起用同一个 `currentTime` 时钟推进。普通台词 TTS 等片段关闭后才继续，避免旁白重叠。seek 同时定位音轨和画面，只恢复当前字幕，跳过已经过去的视觉事件。生成视频可提供自己的 `timeline`，没有字幕时间戳时不会伪造同步。

默认开启片段声音；`muteAll` 和 `volume` 接受主界面的静音与 0..1 音量，`initialMuted` 可设置片段初始静音。浏览器拒绝有声自动播放时停留在封面，用户可点击播放。`AbortSignal`、用户关闭或卸载会停止音频和视频、取消时间轴及延迟回调，并释放当前资源。界面不阻挡底部输入框与麦克风，用户在演出中仍可发起打断。

自动化的动作/配置/元音/时间轴测试位于 `tests/animation.test.mjs`，包含有限点头/挥手、打断后重新计时、视线领先头部、重心与音量平滑、错峰眨眼及变化的注视间隔。实体浏览器的编解码差异仍需持续回归；不支持 alpha 的视频解码器保留主视频，不影响常驻角色交互。
